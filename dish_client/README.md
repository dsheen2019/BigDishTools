# bigdish-client

Client libraries for the Big Dish control protocol described in detail in the BigDishControlServer library. This copy exists as a fallback for users who do not have immediate access to the dish control server repo.

- `bigdish_client.py` — Python, packaged here as `bigdish-client`.
- `bigdish_client.js` — the browser counterpart. Not part of the Python package; a page
  imports it directly. The console UI that used to live here keeps its own copy, in
  [BigDishTools](https://github.com/dsheen2019/BigDishTools/tree/main/bigdish_console), so this one is a reference implementation next to the
  protocol rather than something with a consumer in this repository.

## Installing

```sh
pip install -e ./client                     # from a clone, tracks your edits
pip install "bigdish-client @ git+https://github.com/w1xm/BigDishControlServer#subdirectory=client"
```

Either way the import is the same from any directory, so scripts no longer need to add this
folder to `sys.path`:

```python
from bigdish_client import BigDishClient

with BigDishClient("172.25.15.11", 1234) as dish:
    dish.auth("username", "password")
    dish.init(kick_others = False)
    dish.goto_posvel_azel(180.0, 45.0, 0.0, 0.0)
```

Used as a context manager, or simply left to the interpreter exiting, the connection is
closed properly, so the server releases dish control instead of waiting for the session to
time out.
